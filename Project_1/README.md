## Project Overview
Horology Archive is a multi-page, responsive informational website focusing on mechanical watchmaking history that features a small collection of referenced watches.

## Key Features
- Watch Collection Gallery: Browse a curated collection of iconic mechanical timepieces with summaries on the homepage.

- Watch Specifications: View a comprehensive comparison table covering case sizes, materials, movement details, and technical data.

- Image & Video Showcase: View images of watch models mentioned and watch embedded video of a restoration process.

- Multi-Page Navigation: Easily navigate between the collection, specifications, and media gallery using a clear site-wide navigation bar.

- Responsive Layout: Automatically adjusts page layouts so all content is easy to read on desktop computers, tablets, and mobile devices. 

## File Hierarchy
- `index.html` - Homepage and collection grid
- `specs.html` - Technical specifications and data table
- `media.html` - Image/Video showcase page
- `style.css` - Global stylesheet
- `README.md` - Project documentation
- images/ - Directory containing watch photos for the media page
